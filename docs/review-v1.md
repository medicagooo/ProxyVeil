# v1 review

评审范围：规格与最终源代码的对应关系、写入目标、权限分版、选择性修改、恢复冲突及窗口后台通信。由当前实现者自审；未运行独立评审 agent。

修复后的行为：

- FlClash 偏好重序列化不再阻止还原。引擎只恢复自身变更的字段，保留外部无关字段。
- 配置读写间漂移在备份前、备份后分别检查；不覆盖订阅或策略的外部修改。
- 文本修改、字节还原和失败回退使用同目录临时文件替换，避免中断复制留下半文件。
- 进度读取采用允许并发追加的共享模式。读取失败时仍等待 worker；worker 退出后可直接读取最终结果与快照。
- 窗口在操作期间禁用重复操作与关闭；修复后依据活动快照切换还原按钮。权限受限项显示警告，不打成功勾。
- 普通版不主动提权；管理员入口保留原用户 SID。其他账户的 UAC 拒绝接管。
- 订阅凭据与快照不进入 Git 或 ZIP，生产快照限制目录 ACL。

证据：docs/validation/engine.json、ui-*.json/png、progress.json、packages.json、package-smoke.json；脚本位于 scripts/。源代码恢复、双模式和双版本在夹具运行验证，包解压后再次经过窗口按钮与 worker。

发布边界：没有真实 UAC、真实用户注册表写入、Windows 10 回退和网络泄露复测证据；配置检查不能证明全部流量已隐藏。Proxy 的 DNS 覆盖 Edge，其他程序的 OS DNS 不在首版保护范围。用户需先在现有代理组选择可用节点。FlClash 订阅更新可能覆盖本应用的 YAML；再次修改前先还原并处理冲突。

复核结论：本地源码与便携包验收达成；真实系统兼容与网络隐私验收保留为后续步骤。
